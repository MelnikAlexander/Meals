# Simple Calorie Tracker (Ionic + Angular + NgRx)

This small sample app implements a Meals list stored in NgRx store with actions `addMeal`, `deleteMeal`, `loadMeals` and selectors. It includes a simple Ionic UI (ion-list + modal) and optional persistence in localStorage using `ngrx-store-localstorage`.

# serve in browser
ionic serve
